# Akimbo recipe checkpoint

These 33 unchanged recipes reproduce the October 30 compiler selection across
11 weapon families. They require the development compiler and matching schema 5
Dawn companion described in [Akimbo authoring](../../AKIMBO-AUTHORING.md).
[Checkpoint status](../../AKIMBO-STATUS.md) distinguishes package validation from
pending gameplay acceptance.

Import the `.parhelion.json` files into Parhelion and build the complete selection
against the intended installation. Preserve their authored identities when
updating an existing selection. The recipes use independent hands, the default
360 mm gap and `lower_magazine` reload selection. `selection.json` lists each
filename, item identity, family and SHA-256; it is an index, not a weapon recipe.

Reacquire installed weapons from their ordinary **Collections > Weapons** category.
The Dawn/Sunrise badge is inspect-only. Follow the authoring gameplay checklist
for both inputs, whole-burst ownership, uneven magazines, interrupted reloads,
weapon swaps and tube-fed rounds. These recipes do not grant inventory items or
change infinite-reserve settings.
